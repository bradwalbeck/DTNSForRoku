This file shows the structure of the feed data.
The Roku parser has been inconsistent, but the essential path to the video data for a single episode is as follows.

rss
└── channel
    ├── title (Daily Tech News Show)
    ├── link
    ├── description
    ├── ... (other channel-level tags like itunes:author, etc.)
    │
    └── item
        ├── title (e.g., "DTNS 4859 - When AI Gets Weird")
        ├── description (HTML content of the show notes)
        ├── pubDate
        ├── guid
        ├── ... (other item-level tags)
        │
        └── media:group
            ├── media:content
            │   └── attributes
            │       └── url (This is the streamUrl)
            │
            └── media:thumbnail
                └── attributes
                    └── url (This is the hdPosterUrl)
